# Links úteis para CTF

## Geral / ferramentas de apoio
- CyberChef — https://gchq.github.io/CyberChef/ (decodificar/transformar quase qualquer coisa, funciona offline se salvar a página antes)
- dCode — https://www.dcode.fr/ (identificador e solver de dezenas de cifras clássicas)
- CTFtime — https://ctftime.org/ (referência de writeups de outros CTFs)
- GTFOBins / LOLBAS — https://gtfobins.github.io/ | https://lolbas-project.github.io/ (escalonamento de privilégio com binários legítimos)

## Criptografia / RSA
- RsaCtfTool — https://github.com/RsaCtfTool/RsaCtfTool (várias técnicas de quebra de RSA automatizadas; útil ter clonado antes)
- FactorDB — http://factordb.com/ (banco de fatorações conhecidas de números grandes)
- Alpertron (fatoração) — https://www.alpertron.com.ar/ECM.HTM
- CrypTool-Online — https://www.cryptool.org/en/cto/ (vários algoritmos interativos)
- CrackStation — https://crackstation.net/ (hash lookup, se houver internet)

## OSINT
- OSINT Framework — https://osintframework.com/ (índice de ferramentas por categoria)
- Google Dorks (cheat sheet) — https://www.exploit-db.com/google-hacking-database
- Wayback Machine — https://web.archive.org/
- Shodan — https://www.shodan.io/
- Have I Been Pwned — https://haveibeenpwned.com/
- ExifTool online — https://exif.tools/ (metadados de imagem)
- WHOIS — https://whois.domaintools.com/
- Sherlock (usernames) — https://github.com/sherlock-project/sherlock

## Web Hacking
- PortSwigger Web Security Academy — https://portswigger.net/web-security (labs + teoria, excelente referência rápida)
- PayloadsAllTheThings — https://github.com/swisskyrepo/PayloadsAllTheThings (payloads de SQLi, XSS, SSRF, LFI, JWT etc.)
- HackTricks — https://book.hacktricks.xyz/ (quase um "manual" de técnicas ofensivas)
- jwt.io — https://jwt.io/ (decodificar/forjar tokens JWT)
- SQLMap (docs) — https://github.com/sqlmapproject/sqlmap

## Esteganografia
- StegOnline — https://stegonline.georgeom.net/
- Aperi'Solve — https://aperisolve.fr/ (roda binwalk, exiftool, zsteg etc. tudo junto)
- Binwalk — https://github.com/ReFirmLabs/binwalk
- zsteg (PNG/BMP) — https://github.com/zed-0xff/zsteg

## Phishing / Engenharia Social
- SANS Phishing cheat sheet — https://www.sans.org/security-awareness-training/resources/
- Social Engineering Framework — https://www.social-engineer.org/framework/general-discussion/

## TLS / IPSec / Firewalls / IDS-IPS
- Qualys SSL Labs — https://www.ssllabs.com/ssltest/ (análise de configuração TLS)
- Wireshark — https://www.wireshark.org/ (análise de pacotes/pcap, essencial se o desafio der um .pcap)
- Snort rules docs — https://docs.snort.org/
